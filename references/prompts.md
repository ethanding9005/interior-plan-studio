# 提示词模板库（8 模式）

`{...}` 为变量，用户未指定时用【默认】值。所有模式均为图生图：image1 = 底图，input_fidelity = high。

---

## 模式 1：写实材质平面图

**适用**：任意户型图 → 带真实材质铺装的俯视平面效果图

```
严格保持空间和家具位置轮廓不变，将这张图片转换为室内平面图，写实材质，
客厅地面使用{白色大理石}，厨房卫生间地面{淡色瓷砖}，卧室使用{白橡木}地板。
墙体和窗户保持样式不变。
```

- 变量：`{客厅材质}`【白色大理石，可换奥特曼灰大理石等】、`{厨卫材质}`【淡色瓷砖】、`{卧室材质}`【白橡木地板】
- 增强（实测有效）：追加"俯视正交视角""家具以写实材质呈现""保留原图尺寸标注与文字标注""4K 画质"

## 模式 2：手绘图转 CAD 风格线稿

**适用**：手绘平面草图/照片 → 黑白 CAD 风格标注线稿

```
将这张手绘室内平面图，按以下步骤处理：
识别并列出：所有墙体位置与厚度（外墙/内墙/隔墙）、门的位置、开启方向、宽度；
窗的位置、宽度；所有功能空间名称；固定家具或卫浴设备。
对识别结果进行合理化修正：将手绘的歪斜线条矫正为正交直线，推断合理的建筑尺寸；
补全不清晰或缺失的墙体与门洞。
输出 CAD 风格线稿，要求：用粗线画墙体轮廓；墙体填充为黑色实体；门窗用完整线条表示；
阳台用三线表示（外墙线 + 两条细线）；标注各房间名称；标注轴距尺寸（开间×进深，单位 mm）；
整体比例统一；白底黑线。
```

## 模式 3：空户型家具布置图

**适用**：只有房间名、没有家具的空户型 → 现代简约家具布置平面图

```
这是一张室内空户型平面图，图中已标注各房间名称，无具体尺寸。
请根据图中墙体结构和房间标注，合理推断各空间面积比例，为每个房间配备符合人体
工程学的家具布置。客厅放置沙发、茶几、电视柜、沙发背景墙装饰画；餐厅放置餐桌餐椅；
主卧床头靠墙，配衣柜；次卧按卧室布置；厨房按洗切炒动线排列橱柜；
卫生间布置马桶、洗手台、淋浴区。
家具用视觉平面图形式表示，线条简洁，风格为现代简约。
整体保持原户型墙体结构不变，输出完整的室内平面布置图。
```

## 模式 4：空白平面功能布局

**适用**：空白建筑平面图 → 指定业态的功能平面布局

```
基于我上传的空白平面图，在不改变原始建筑结构、承重墙位置和外轮廓的前提下，
生成现代简约{咖啡厅}的功能平面布局方案。
布局逻辑要求：动线清晰、功能分区合理、空间流线简洁。
生成标准建筑平面表达，输出为：专业室内平面布局图，黑白极简风格，逻辑合理正确。
```

- 变量：`{业态}`【咖啡厅；可换办公室、餐厅、书店、民宿大堂等，同时把功能分区写进提示词，如卡座区/吧台水吧/操作间/男女卫/外摆区】

## 模式 5：家具尺寸与人体尺度分析图

**适用**：户型平面图 → 黑白银灰建筑分析图（尺寸引线 + 人体模型）

```
基于我上传的户型平面图，以原图为底图进行分析表达，不改变空间结构与比例。
生成一张室内家具尺寸与人体尺度分析图：在平面图中标注主要家具尺寸（{沙发长度、
餐桌尺寸、床的宽度}），标注关键通行尺度（{走道宽度、过道净距}），叠加人体尺度模型，
用清晰的线性标注与尺寸引线表达。每条标注均为一条带端点的细引线连接尺寸数字，密集且精确。
左侧设置图例区：HUMAN SCALE 人体尺度图例表 + DESIGN NOTES 设计说明文字块。
画面风格偏建筑分析表达，黑白或淡灰为主，保持专业、理性、信息清晰有层级。
整体风格：建筑性表达，线性克制，信息清晰有层级。
```

- 有参考版式截图时作 image2，追加"参考第二张图的版式与标注风格"

## 模式 6：9 页方案汇报 PPT（九宫格）

**适用**：户型平面图 → 一张 3×3 九宫格呈现 9 页汇报版式

```
基于指定室内平面图，生成一套完整室内设计方案汇报 PPT（9页），以 3×3 九宫格排入一张画面，逻辑架构如下：
1. 封面（{项目名称}、平面图缩略图、设计风格标注）；
2. 目录（清晰列出报告章节）；
3. 平面图解析（标注空间分区、动线规划、功能定位）；
4. 设计理念与风格定位（明确风格关键词 + 色彩主题色卡）；
5. 主卧空间方案（平面简图 + 设计意向图 + 材质质感 + 尺寸标注）；
6. 核心公共区（材料样品配色、家具选型、平面图功能要点）；
7. 整体效果图（全景氛围图 + 单面渲染对照）；
8. 致谢页（联系方式占位）；
9. 备用页（空间格局延展）。
整体氛围安静高级、{低饱和奶油灰调}，版面干净利落有杂志编辑感，层级清晰，正式又不呆板；
所有页面围绕原始平面图的空间格局展开设计，不偏离户型核心。
```

- 变量：`{项目名称}`【室内设计方案汇报】、`{色调}`【低饱和奶油灰调】
- 交付时说明：图中文字为 AI 生成、可能不可读；需要真实可编辑 .pptx 另行走 PPT 流程

## 模式 7：三色动线分析图

**适用**：户型平面图 → 生活/家务/访客三色动线 + 功能色块分析图

```
将户型平面图生成一份居家动线设计的分析平面图。包含以下元素与要求：
1. 红色虚线标注「生活动线」：从入户门开始，覆盖餐厅、厨房与卫生间的日常起居流动路径；
2. 绿色虚线标注「家务动线」：连接厨房、餐厅与家务作业流动路径；
3. 蓝色虚线标注「访客动线」：从入户门开始，覆盖客厅、公共区域与待客活动流动路径；
动线均用带箭头的彩色虚线，沿真实走廊与门洞走向绘制；
4. 空间着色区块：客厅、卧室、餐厨、卫生间、活动区使用半透明马卡龙色块区分类型，
色块不遮盖家具轮廓；
5. 右下方添加图例说明（Legend）：功能区块颜色与对应类型、三种动线颜色与对应类型；
6. 不改变原图空间结构与比例，家具位置不变；
整体为专业室内设计分析图，半透明色块区分功能区，层级清晰，正式质感。
```

## 模式 8：空间区域 4K 实景效果图

**适用**：户型平面图（可在图上框选区域并画视角箭头）→ 指定区域人视实景渲染

```
基于上传的平面户型图，生成户型平面图中红框内的【{客厅}区域】的 4K 室内效果图，
必须保持房间布局和软硬装家具布置与户型平面图一致。
从箭头方向看去：{左边是电视柜背景墙，中间是沙发客厅区域，有地毯，右边是餐厅，
远景是落地窗阳台，有绿植}。
严格按照户型图的家具布局和空间结构，整体风格{现代轻奢风}，精致的效果图，室内设计效果图。
```

- 变量：`{区域}`【客厅，可换主卧/餐厅/玄关】、`{朝向布局描述}`【按底图实际家具关系改写】、`{风格}`【现代轻奢风】
- 有实景参考图时作 image2，追加"参考第二张图的空间氛围与材质"
- 人视角度默认"站在区域中央朝{阳台/窗户}方向"
