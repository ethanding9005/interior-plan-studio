# interior-plan-studio 室内设计出图助手

把户型图 / 平面图 / 手绘草图一键转换为 8 种专业室内设计图的 AI 技能（图生图 + 锁定底图）。

## 8 种输出

| # | 模式 | 适用输入 |
|---|------|----------|
| 1 | 写实材质平面图 | 任意户型图 |
| 2 | 手绘图转 CAD 风格线稿 | 手绘草图/照片 |
| 3 | 空户型家具布置图 | 有房间名无家具的空户型 |
| 4 | 空白平面功能布局 | 空白建筑平面（默认咖啡厅，可换业态） |
| 5 | 家具尺寸与人体尺度分析图 | 户型平面图 |
| 6 | 9 页方案汇报 PPT（九宫格） | 户型平面图 |
| 7 | 三色动线分析图 | 户型平面图 |
| 8 | 空间区域 4K 实景效果图 | 户型平面图（可框选区域） |

## 安装

将本仓库克隆到 WorkBuddy / CodeBuddy 的技能目录：

```bash
git clone https://github.com/ethanding9005/interior-plan-studio.git ~/.workbuddy/skills/interior-plan-studio
```

重启会话后即可触发；或直接把 `SKILL.md` + `references/prompts.md` 复制到任意支持 Agent Skills 的客户端技能目录。

## 使用

1. 上传底图（户型图 / 平面图 / 手绘图）
2. 说明想要哪种输出（如「转材质平面图，客厅用灰色大理石」）
3. 技能自动匹配模板 → 图生图（高保真锁定底图）→ 出图 → 可局部迭代修改

## 文件结构

```
interior-plan-studio/
├── SKILL.md              # 触发描述 + 工作流 + 模式速查表
└── references/
    └── prompts.md        # 8 条提示词模板（材质/风格/业态/视角可变量替换）
```
